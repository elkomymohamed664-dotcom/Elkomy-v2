# PHYTO MOTION — الإصدارات العلمية الكاملة

موقع مستقل لعرض **الكتيّبين الأصليين كاملين**، وليس ملخصات. له بوابة رئيسية وقارئان خاصان، ولا يحتاج إلى الصفحة الرئيسية للمشروع أو ملفاتها. اختر دليل المريض أو المرجع الأكاديمي لفتح الإصدار المناسب.

## الكتيّبات

- `patient-book.html` — دليل المريض والزائر، **٨ صفحات**.
- `clinician-book.html` — المرجع الأكاديمي للطبيب والصيدلي، **٤ صفحات**.
- `index.html` — بوابة اختيار الكتيّب.

تُعرض كل صفحة وفق تصميم المصدر، ويظهر نصها الكامل للمراجعة والبحث والنسخ. الشعارات والصفحات محفوظة محليًا داخل `assets/`، دون اعتماد على خدمة خارجية. التنقل متاح بأزرار السابق/التالي، أو مفاتيح الأسهم، أو السحب على الهاتف. يضيف القارئ فهرسًا مصغّرًا للصفحات، وبحثًا عربيًا/إنجليزيًا داخل النصوص مع تمييز النتائج والانتقال إليها، وبطاقات تفاعلية للنباتات تربط إلى صفحاتها. يستخدم المرجع الأكاديمي قراءة الجهاز للنصوص المحددة. أما دليل المريض فيتضمن زرًا مستقلًا لكل صفحة يشغّل تعليقًا صوتيًا مصريًا مولّدًا ومخصصًا لمحتواها، مع بقاء التسجيل المصري الأصلي الكامل خيارًا منفصلًا. النقر على كلمة أو سطر أو صف جدول يقرأ النص المحدد بصوت الجهاز فقط. تحفظ نصوص التعليق في `assets/audio/patient-page-narration-ar-eg.json`، وتوثق `assets/audio/patient-page-audio-ar-eg.json` ملفات الصفحات ومددها. تحاول بوابة الإصدارات تشغيل إرشاد الترحيب تلقائيًا، مع زر يدوي واضح للمتصفحات التي تمنع التشغيل التلقائي. يظل زر الصوت العلوي مخصصًا لنغمات التظليل وتقليب الصفحات. يدعم القارئ إعداد تقليل الحركة والطباعة.

## تشغيل محلي

من داخل هذا المجلد:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

ثم افتح `http://localhost:8000/`؛ ستظهر بوابة الموقع المستقل مباشرة.

## نموذج التواصل وواجهة API

يظهر نموذج التواصل في `index.html` ويرسل إلى `POST /api/contact`، حيث يتحقق الخادم من المدخلات ومصدر الطلب والحجم، ويستخدم حقلًا مخفيًا وحدًا مبدئيًا للمحاولات المكررة. تسليم البريد يتم عبر Resend، ومفتاحه لا يظهر في كود المتصفح.

يلزم ضبط متغيرات بيئة الإنتاج في Vercel قبل تفعيل الإرسال:

- `CONTACT_TO_EMAIL` — عنوان الاستلام.
- `CONTACT_FROM_EMAIL` — عنوان إرسال موثّق في حساب Resend، مثل `PHYTO MOTION <contact@your-verified-domain>`.
- `RESEND_API_KEY` — مفتاح Resend، ويُحفظ كمتغير حساس في Vercel فقط؛ لا تضعه في Git أو المتصفح.

إذا لم يكتمل إعداد المرسل والمفتاح، يعيد الـ API حالة `503` بدل الإيحاء بأن الرسالة أُرسلت. خادم `python3 -m http.server` يعرض الصفحات الثابتة فقط ولا يشغّل دوال `/api`.

## النشر

يُنشر موقع الكتيّبات مستقلًا على Vercel من المجلد `booklet-site/`، دون الاعتماد على الصفحة الرئيسية للمشروع. الرابط المباشر: <https://phyto-booklets.vercel.app/>. صفحات الكتيّبات وأصولها محلية ولا تحتاج إلى أمر بناء أو اعتماديات؛ واجهة التواصل تعمل كدالة Vercel منفصلة عند اكتمال إعداد متغيرات البريد أعلاه.
