# PHYTO MOTION — الكتيّبات الكاملة بصيغة HTML

بوابة مستقلة تعرض **الكتيّبين الأصليين كاملين**، وليس ملخصات. اضغط خانة المريض أو الطبيب/الصيدلي لفتح قارئ HTML منفصل للكتاب المناسب.

## الكتيّبات

- `patient-book.html` — دليل المريض والزائر، **٨ صفحات**.
- `clinician-book.html` — المرجع الأكاديمي للطبيب والصيدلي، **٤ صفحات**.
- `index.html` — بوابة اختيار الكتيّب.

كل صفحة مصدر تظهر كورقة مطابقة لتصميم الكتيّب الأصلي، ومعها نص HTML قابل للبحث والنسخ من قسم «عرض نص الصفحة». الصور محلية داخل `assets/`؛ لا يوجد عارض PDF أو اعتماد على خدمة خارجية. التقليب متاح بالسحب على الهاتف، أزرار السابق/التالي، أو مفاتيح الأسهم. صوت تقليب الورق يُولّد محليًا عبر Web Audio ويمكن كتمه، والطباعة تعرض صفحات الكتاب كاملة.

## تشغيل محلي

من جذر المستودع:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/booklet-site/`.

## النشر

تُخدم الملفات الثابتة من جذر المستودع على GitHub Pages في `/Elkomy-v2/booklet-site/`، وتفتح خانات المكتبة في `index.html` قارئي المريض والمرجع مباشرة. لا يلزم أمر بناء أو اعتماديات أو تعديل إعدادات Vercel للموقع الأساسي.
